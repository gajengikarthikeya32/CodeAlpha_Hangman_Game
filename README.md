# CodeAlpha Hangman Game

## About the Project
This is a simple text-based Hangman game developed
using Python as part of the CodeAlpha internship.

## Features
- Randomly selects a word from a predefined list.
- Allows a maximum of 6 incorrect guesses.
- Accepts one letter at a time.
- Displays the guessed letters.
- Announces whether the player wins or loses.

## Technologies Used
- Python
- Random module

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python hangman.py
